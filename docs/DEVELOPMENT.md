# 개발 문서

## 구조

```
원본.hwpx ─ extract ─▶ content.json + images/ ─ build(샘플.hwpx) ─▶ 결과.hwpx
                                      ▲                                   │
                                      └──────── fit(결과.pdf) ◀── pdf ────┘   (쪽 맞춤 반복)
check: 결과.hwpx 를 다시 extract 해서 원본 content.json 과 블록 단위 비교(내용 보존)
```

| 모듈 | 역할 |
|---|---|
| `common.py` | 네임스페이스, 정규식(장 제목·절 번호·숫자 칸·합계 행), 제목 개체 판별(`heading_of`), 간지 목록(`toc_items`), 보고서 제목(`report_title`) |
| `extract.py` | 원본 → 중간포맷. 서식은 버리고 텍스트·표 격자·그림·제목 번호·구역 방향·바탕쪽 그림만 |
| `template.py` | 샘플 분석: 간지 문단들, 장 제목, 수준별 절 제목 개체(표·글상자), 스타일별 문단 원형, 표 역할별 서식(머리행·숫자·항목·합계), 행 높이, 그림틀, 쪽 관련 조판 부호, 구역 정의(방향별) |
| `build.py` | 조립: 원형 복제 + 번호·제목 교체(`retext`, 글자 조각 서식 유지), 표 조판(열 폭·합계 행 채움·긴 표 쪽 나눔), 그림 크기 맞춤, 구역·조판 부호 부착, 헤더(번호 형식·새 테두리)·바탕쪽(장 제목·보고서 제목·장별 그림) 치환 |
| `check.py` | 내용 보존 검사 |
| `fit.py` | 쪽 맞춤(PDF 분석 → 쪽 나눔 조정) |
| `mcp_server.py` | 위 기능을 MCP 도구(stdio)로 노출. `hwpx-restyle-mcp` |

## 설계 원칙

1. **서식은 샘플에서만 가져온다.** 한글 XML을 새로 짓지 않고 샘플의 원형을 복제한다 → 한글이 받아들이는 형태가 보장된다.
2. **스타일 이름·ID를 하드코딩하지 않는다.** 샘플마다 자동 분석한다(서식 계열이 달라도 동작).
3. **쪽 배치가 스타일보다 우선이다.** 한 쪽에 깔끔하게 들어가는 배치와 원본 스타일이 충돌하면 자간·줄 간격·표 글자 크기·쪽 나눔을 조금 바꾼다. 사람은 스타일이 조금 달라도 알아채지 못하지만, 빈 쪽이나 쪽 끝에 홀로 남은 제목은 바로 알아챈다.
4. **표**: 내용 숫자는 흰 바탕, 계·합계·소계 행만 옅은 배경(샘플 합계색이 옅으면 그 색, 아니면 `#F2F2F2`).
5. 그림은 비율 유지, 계산식 필드는 값으로.

## 검증 방법

- `check`: 한글 없이 몇 초. 모든 수정 뒤에 돌린다.
- `pdf` + `sheet`: 한글 COM으로 PDF → 쪽 썸네일 비교. **한 번에 하나씩만**(동시 실행하면 한글이 멈추거나 죽는다).
- `tools/convert_queue.sh`: 여러 결과를 차례로 변환. `tools/pdf_timeout.py`: 시간 제한(멈춤 감지).
- `tools/bisect_mid.py`: 한글이 멈추는 파일을 블록 구간으로 잘라 원인 블록 찾기.
- `tools/outline.py`: 새 서식 계열 분석용 문단 목록 덤프(스타일·표·글상자 글자).

## 알려진 함정과 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 한글에서 안 열림 | 간지가 구역 정의(secPr) 문단이라 복제 시 secPr 2개 | 복제 시 secPr·colPr 제거, 구역 시작에만 부착 |
| 머리말·쪽번호 사라짐 | 일부 계열은 머리말이 본문 제목 문단의 조판 부호 | 샘플의 쪽 관련 부호를 모아 장 제목(앞의 것은 간지)에 부착 |
| 그림이 엉뚱하게 큼 | 그림 원형으로 묶음(그룹) 안 하위 그림을 씀(pos·sz 없음) | 독립 그림만 원형, 없으면 내장 `pic_proto.xml` |
| 쪽 수 급증 | 샘플 행 높이(두 줄 칸 기준)를 그대로 씀 | 한 줄 짧은 칸 높이와 글자 크기 계산값 중 작은 쪽 |
| 긴 표가 통째로 다음 쪽 | 글자처럼 취급 + 샘플의 쪽 나눔 없음 | 데이터 표 `pageBreak=CELL`, 15행 이상은 글자처럼 취급 끔 |
| 머리말 장 제목이 그림 | 장별 배너가 바탕쪽 그림 | 샘플에만 있는 바탕쪽 그림 ↔ 원본에만 있는 그림을 비율로 짝지어 교체 |
| WMF/EMF 크기 | PIL 미지원 | 파일 머리 파싱 → 원본 orgSz |
| 한글이 조판 중 무한히 멈춤 | 글자 요소 안의 날것 탭 문자(`\t`) | 탭은 `<hp:tab/>`, 줄바꿈은 `<hp:lineBreak/>` 요소로 |
| 수식 누락 | 추출이 hp:equation 무시 | 수식 스크립트·크기 보존 후 재생성 |
| 한글 COM 실패·멈춤 | 창 없는 Hwp.exe 잔존, 백그라운드 셸 잔존 | 변환 전 정리, 시간 제한 |
